撲螢 — 像素貓追螢火蟲

Pixel Splat Short · made with ink studio

這是什麼

一支 18 秒的像素短片。圓胖的英短藍貓趴低盯著一隻螢火蟲，一撲出去就連跳好幾下追，每一腳落地，地上都盪開兩圈青色的螢光水紋。

螢火蟲鑽進草叢，一隻奶油色小貓從裡面探出頭，頭的外圍爆出一圈亮粉。兩隻歪頭互看，接著站起來互拍、側躺扭打、上下互換，最後藍貓掙脫跑開，奶油小貓追過去，一前一後跑出畫面，只留下慢慢淡掉的水紋。

靈感來源

siliconjungle/shapeshift-labs-ink-studio：一套 JavaScript 工具，用有號距離場（SDF）雕出立體形狀，再烘成像素風的 Gaussian splat，可以做動畫、粒子和物理。這支片不是 three.js，而是用它的 CLI 在 Node 裡逐格渲染出來的。

作法簡介

  • 角色：兩隻貓用同一個雕塑函式捏出來，只差面向和毛色；臉（眼睛、鼻子）直接畫在頭的材質上。
  • 動作：每一次跳躍寫在一張跳躍表裡（起訖時間、位置、高度）；貓的位置、腿的擺動、身體俯仰、落地壓扁和水紋出現的時機，全部從這張表算出來，改節奏只要改表。
  • 扭打：下面那隻側躺、後腳快速連踢，上面那隻用前腳輪流拍；因為明暗是雕刻時就固定的，翻成肚子朝天會變成一團暗色，所以最多只側躺 50 度。
  • 特效：水紋每格重畫，外圈先擴散、內圈晚一點跟上，由亮青轉青再淡掉；冒頭的亮粉是 48 顆粒子從頭的外圍往外散。
  • 輸出：用 ink-studio clip 以 24fps 渲染成動畫 PNG，再用 ffmpeg 最近鄰放大兩倍、轉成 1200 × 840 的 mp4。
