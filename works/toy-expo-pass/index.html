Toy Transit — 玩具展雷射乘車證

Holographic Expo Pass · CSS 3D · Three.js

「玩具轉運站」是一個虛構的玩具展：被收進抽屜的老玩具在這裡轉車，有的被修好，有的遇到新主人。這張是寄給你的首班車乘車證。撕開封蠟，票會從信封裡飛出來；轉動它看雷射光流動，翻到背面是展覽主視覺「首班車月台」。鐵皮兔站長扣扣會幫你剪票，展後再蓋上「已抵達」郵戳。

靈感來源

  • 靈感來自東京 AI 影像創作者 KANA 的 「HAPPINESS PASS しあわせパス」（pass.tokyoaivisuals.club）：一個免費、不用註冊的動態邀請卡產生器。這張乘車證借用了登機證式電子票、閃卡雷射材質和拆信儀式這種形式；角色、文案、配色和版面都是為這個虛構展覽重新設計的。

作法簡介

  • 票和信封：用 CSS 3D 做，正反兩面靠 backface-visibility 切換。票上的字都是真的文字，不是圖片，放大也清楚。
  • 雷射材質：四層疊在一起。最底下是紙紋雜訊；上面一條彩虹漸層，跟著傾斜角度移動 background-position；漸層只從星星網點的 mask-image 裡透出來；最上面一個白色光點，往傾斜的反方向移動，像被燈照到。
  • 傾斜：電腦看滑鼠位置，手機看陀螺儀（iOS 在按「開封」時請求權限），沒有陀螺儀時改成用手指拖曳。數值都經過平滑處理，轉起來不會抖。
  • 站長扣扣：舊舊的鐵皮玩具，在Tripo將2D設計轉成3D模型，再做減面和壓縮貼圖。模型沒有骨架，跳躍、剪票、蓋章都是整隻身體的位移、旋轉和擠壓伸展。扣扣住在郵票裡時，用 WebGL 的 scissor 把畫面裁成郵票的範圍；郵票上的郵戳另外疊一張跟著票一起轉的「影子票」，才能壓在扣扣上面。
  • 背面「首班車月台」：月台、火車和兩位貓乘客也是做舊的復古玩具風格，在Tripo將2D設計轉成3D模型，再做減面和壓縮貼圖。鏡頭跟著票的傾斜繞動，前景動得比遠景多。火車一直循環進站、停靠、出站。
  • 開封儀式：封蠟彈起、信封蓋翻開、票滑出來飛到眼前，到位時一陣閃光和碎紙。碎紙是一張 2D canvas，紙片有重力和空氣阻力。

可以怎麼玩

  • 點封蠟或按「開封」（鍵盤 O）。
  • 移動滑鼠或轉動手機，看雷射光在票面上流動。
  • 按「翻面」（F）看背面的月台主視覺。
  • 切換「待出發／已上車／已抵達」（1–3）：扣扣會跳出郵票剪票，或像印章一樣蓋上郵戳。
  • 切換「被邀請／自己買」，看邀請人欄位和背面行李吊牌上的訊息怎麼變。
  • 按右下的重新開封（R），把票收回信封再拆一次。
