# TOY TRANSIT 玩具轉運站 — 企劃書

> 給被收進抽屜的玩具，一張回程票。

這是一場虛構的玩具展，也是 sui's playground「雷射票」範例的設定。展覽、地點、角色和票價都是虛構的，用來說明一張數位入場券從購買、邀請、入場到展後留念的完整生命週期。

### 2. 主題與策展論述

每個人家裡都有一個抽屜，裡面躺著不再玩、也捨不得丟的玩具：缺一隻腳的機器人、掉漆的鐵皮車、扭蛋機轉出來的小動物。它們沒有壞，只是停在某一站，等人來接。

「玩具轉運站」把展場想成一座車站。玩具從各自的抽屜出發，在這裡轉車：有的被修好，有的被重新講述，有的遇到新的主人。參觀者拿到的不是門票，而是一張「乘車證」，跟著玩具一起經過四個月台，最後在轉運郵局寄出一張明信片，把這段旅程帶回家。

策展上想談三件事：

1. **玩具是記憶的載具**：展出的老玩具都附上原主人的手寫故事，玩具本身不是重點，重點是它陪過誰。
2. **會動的玩具保有魔法**：發條、齒輪、小燈泡這些簡單的機關，不管過了幾十年，啟動的那一刻還是讓人屏息。
3. **新的玩具也在出發**：邀請台灣與亞洲的獨立設計師玩具創作者，讓老玩具和新作品在同一個月台相遇。

### 3. 展區（四個月台）

動線照車站的方式編號，參觀者從 A 月台進站、D 月台出站。

| 月台 | 展區名稱 | 內容 | 互動 |
| --- | --- | --- | --- |
| GATE A | 失物招領處 | 徵集 300 件民眾家中的老玩具，每件附一張原主人寫的「招領單」，寫下它怎麼來、陪了誰、為什麼停在抽屜裡 | 參觀者可以在空白招領單上寫自己的玩具，貼上留言牆 |
| GATE B | 夜行列車 | 全暗的長廊，展出會發光、會動、有發條機關的玩具，像一列夜車從身邊駛過 | 拉動月台上的號誌桿，啟動不同車廂的機關 |
| GATE C | 新住民候車室 | 24 組獨立設計師玩具創作者的新作，以「候車」為題，每組各做一件「正要出發」的角色 | 限量展覽聯名扭蛋，只在這裡販售 |
| GATE D | 轉運郵局 | 出口前的郵局櫃台。蓋紀念戳、寄一張明信片給一年後的自己（主辦方於 2028 年 1 月統一寄出） | 持票在櫃台核銷「已抵達」，數位票轉為紀念存根 |

### 4. 主角與代表展品

**站長「扣扣」（KOKO）**
展覽的原創角色。一隻發條鐵皮兔，戴著過大的站長帽，背上有一把轉不完的發條，手裡拿著剪票鉗。名字來自剪票鉗「扣、扣」的聲音。個性有點迷糊，總是在找某一班誤點的車。扣扣會出現在主視覺、票面郵票、場內指標和紀念戳上。

**代表展品**
- 〈缺一隻腳的機器人 No.0047〉— GATE A。1983 年的塑膠變形機器人，招領單上寫著「哥哥出國那年留給我的，左腳在搬家時不見了」。閉展日當天，原主人會親自來把它領回家。
- 〈月台上的發條遊行〉— GATE B。40 隻發條玩具排成一列，每 15 分鐘同時上發條走一圈。
- 〈候車中〉系列 — GATE C。24 位創作者各做一隻拎著行李箱的角色，一起排在長椅上。
- 〈招領郵筒〉— GATE D。參觀者寫給未來的明信片投進這座 2.4 公尺高的郵筒。

### 5. 主視覺方向

- **概念**：一張從玩具抽屜裡被翻出來的舊車票，在燈下一轉，表面閃出彩虹光。懷舊的紙質感加上閃卡的雷射光，代表「老玩具被重新看見」。
- **配色**：奶油白紙底，搭配鐵皮玩具常見的三個顏色：番茄紅、鐵皮藍、芥末黃，再加上深墨藍做文字和線條。雷射材質只用在票面和少數重點，不鋪滿畫面。
- **圖像元素**：站長扣扣、剪票孔、郵戳、月台編號、軌道線、發條鑰匙。
- **字體**：英文大標用粗黑的無襯線體（呼應 sui.funkuki.com 的 Inter 800），中文用圓潤的黑體；票號、時間這類資訊用等寬字，像車票上的打印字。
- **延伸物**：主海報、乘車證（數位與實體）、月台指標、紀念戳、明信片、扭蛋包裝。

### 8. 邀請制玩法：「轉乘券」

首班車之夜不賣票，只能被邀請。邀請的單位叫「轉乘券」，就像車站讓你帶朋友轉乘同一班車。

**誰可以邀請**
- 首發乘客（購買套票）：2 張轉乘券
- 早鳥票持有人：1 張轉乘券
- 創作者、借展者、媒體：由主辦方直接發出首班車通行證，各附 1 張轉乘券

**怎麼邀請**
1. 持票人在自己的乘車證背面按「送出轉乘券」，產生一條專屬邀請連結，可以附一段手寫訊息（最多 60 字）。
2. 朋友打開連結，看到一個信封，點開後收到自己的首班車通行證。票面的「TRANSFER FROM」欄位會寫上邀請人的名字，背面是邀請人的手寫訊息。
3. 被邀請的人不能再往下邀請，讓首班車維持在約 400 人的規模。
4. 轉乘券在 1/20 23:59 前未被領取就會失效，額度退回主辦方，改為現場抽籤釋出。

**為什麼這樣設計**
- 首日的觀眾是「被朋友帶來的人」，而不是搶票最快的人，現場氣氛會更像一場聚會。
- 邀請本身就是一份小禮物：收到的人先拿到一個信封，開封的過程是整個體驗的第一個驚喜。
- 票面記錄了「誰帶誰來」，展後成為一張有故事的紀念品，呼應展覽「玩具陪過誰」的主題。

## 第二部分：視覺規劃

第二部分分成兩塊：A 是展覽本身的主視覺系統（海報、指標、周邊共用的規則），B 是雷射乘車證的設計與互動。乘車證是主視覺系統裡最重要的一個應用，所以兩者共用同一套顏色、字體和圖形元素。

### A. 展覽主視覺

#### A1. 視覺概念：「首班車月台」

主視覺是一座玩具車站的月台，像桌上的微縮模型，用略低的 3/4 視角拍。一列鐵皮小火車（紅黃藍的火車頭加三節客車）剛進站，紅色雨棚下有長椅、售票機、站牌和路燈，月台邊堆著皮箱和包裹。老玩具乘客提著行李在月台上候車，有的站著、有的坐著等。站長扣扣站在月台邊、拿著剪票鉗迎接每一位乘客。後方是圓圓的玩具樹和模糊的遠景。

抽屜不再畫進主視覺，只留在故事裡（文案「給被收進抽屜的玩具，一張回程票」不變）：玩具已經從抽屜出來，現在站在月台上等首班車。雷射乘車證是它們手上的那張票。

一句話說：**老玩具在月台上，首班車剛剛進站。**

#### A2. 風格：鐵皮印刷

整個系統借用老鐵皮玩具的平版印刷質感，而不是光滑的向量插畫：

- **平塗色塊**：每個物件只用 2～3 個顏色，沒有漸層（雷射材質例外）。
- **套色偏移**：色塊和黑色線稿故意錯開 1～2 px，像印刷時沒對準版。
- **網點陰影**：陰影用芥末黃或鐵皮藍的圓網點，不用灰色。
- **紙與鐵皮的磨損**：邊角有細微的掉漆刮痕和紙纖維，強度很低，只在放大時看得出來。

雷射材質是這套懷舊系統裡唯一「新」的東西，所以只用在乘車證、主標題的描邊和少量周邊（扭蛋包裝的封口貼），讓它一出現就是焦點。

#### A3. 配色

| 名稱 | 色碼 | 用途 |
| --- | --- | --- |
| 奶油紙 | `#F6EFE2` | 主背景、明信片底 |
| 牛皮卡 | `#E9DCC4` | 次要底色、票根、信封 |
| 番茄紅 | `#E2483A` | 主色，站長帽、主要按鈕、GATE C |
| 鐵皮藍 | `#2F5DA8` | 主色，扣扣身體、軌道、GATE D |
| 芥末黃 | `#E9B53C` | 輔色，網點、強調、GATE A |
| 深墨藍 | `#1E2A44` | 文字、線稿、GATE B（夜行列車） |
| 郵戳紫 | `#6B4E9B` | 只用在郵戳和「已抵達」狀態 |

#### A5. 圖形元素

- **月台圓牌**：直徑固定的實心圓，裡面是月台字母（Inter 800），外圈有一圈細白線。指標、票面、紀念戳都用它。
- **軌道線**：兩條平行細線加上等距枕木，當作分隔線和動線指示。
- **剪票孔**：一個小小的圓角梯形缺口，出現在已核銷的票、海報角落、網站按鈕的 hover。
- **郵戳**：雙圓圈、上下弧形文字、中間日期，邊緣有不規則的墨色斷點。
- **發條鑰匙**：扣扣背上的發條，簡化成 icon，當作「開始／啟動」的符號。
- **郵票鋸齒**：郵票狀的鋸齒邊框，用在乘車證的主視覺區和社群貼文的圖框。

#### A6. 站長扣扣的造型規範

- **比例**：二頭身，頭和身體一樣大，耳朵直立時約等於頭高。
- **配色**：身體鐵皮藍，肚子奶油紙色，站長帽番茄紅加芥末黃帽徽，發條是黃銅色（芥末黃加深墨藍線）。
- **表情**：只有兩顆點點眼和一條小嘴，靠耳朵角度表達情緒：直立（精神）、一隻折下（困惑）、兩隻垂下（誤點了）。
- **標準姿勢**：剪票（主視覺）、看懷錶（指標「請稍候」）、揮旗（入口）、蓋章（轉運郵局）。
- **2D 與 3D 兩個版本**：2D 是鐵皮印刷插畫，用在海報、郵票、紀念戳；3D 是一隻「真的鐵皮玩具」，用在網站和數位乘車證。3D 版用定稿的 2D 圖生成產品照，再用 Tripo／Meshy 轉成 GLB；背上的發條鑰匙另外做成獨立物件，在網頁上會一直轉。生成用的 prompt 寫在 [PROMPTS.md](PROMPTS.md)。

### B. 雷射乘車證

#### B1. 尺寸與方向

- **電腦版**：橫式，寬高比 2.4 : 1（例如 720 × 300 px），像一張長車票。
- **手機版**：直式，寬高比 1 : 2.2，三個區塊由上到下排列。存根在最下面，撕線變成橫向。
- 圓角 14 px，四個角的其中兩個（存根兩側）有半圓打孔。

#### B2. 正面版面（橫式，由左到右）


1. **郵票區（左，約 28%）**：鋸齒邊的郵票，芥末黃底，裡面住著 3D 扣扣（不是 2D 插畫）：開封後扣扣跳進郵票，在郵票框裡慢慢自轉，並跟著票一起傾斜。郵票右下角壓著一個半透明的出發郵戳「汐見港 2027.01.23」。郵票的框是雷射材質。

4. **存根（右，約 22%）**：牛皮卡底色，不上雷射，讓 QR code 容易掃。內容：BOARDING PASS、票號 `TT-0123-A-0047`、QR code、日期時段。已上車後在存根上方出現剪票孔。

整張票的底色是奶油紙，雷射只出現在三個地方：郵票框、直排大標、票面上的星星網點。

#### B3. 背面：主視覺明信片

背面是整張票最值得留下來的部分，所以放的是展覽主視覺「首班車月台」，而不只是資訊。展後票變成紀念存根時，翻過來就是一張完整的主視覺小卡。

**3D 月台場景（滿版）**
背面是一個小小的 three.js 場景，用固定的 3/4 鏡頭拍月台。票傾斜時，鏡頭跟著小幅繞動（約 ±6°），前景的扣扣和乘客動得比後面的月台和遠景多，看起來像在看一座真的微縮模型。只從一個方向看，所以背面看不到的地方不用做細。

| --- | --- | --- |
| 遠景 | 2D 圖片 | 天空、模糊的樹林，貼在最後面的一塊平面上 |
| 月台 | Tripo（`platform2.png`） | 月台本體、軌道、紅色雨棚、長椅、售票機、站牌、路燈、行李和玩具樹，整座一個模型 |
| 火車 | Tripo（`train.png`） | 火車頭加三節客車一個模型，在月台前的軌道上循環：從左邊減速進站、停靠約 3.5 秒、再加速往右出站，每次翻到背面都重新進站 |

**疊在主視覺上的資訊**（網頁文字，不畫進圖裡）
- **左上**：「TOY TRANSIT 玩具轉運站」小標和展期，像海報的縮小版。
- **右下角**：一張綁著細繩的**行李吊牌**，上面是給收票人的訊息（Noto Sans TC）。自己買的票寫扣扣的話，被邀請的票寫邀請人的話，最上面一行是「FROM 阿光」。吊牌會跟著傾斜晃一下。
- **底部**：一條深墨藍的時刻表資訊列：乘客、時段、座位、地點，用打印字。
- **右上**：郵票框。「已抵達」時郵戳蓋在郵票和主視覺上，壓到插畫，像真的蓋過的明信片。

#### B4. 雷射材質做法

以 CSS 3D 來做（理由見 B7），材質由下到上疊四層：

1. **紙底**：奶油紙色加一層很淡的雜訊紋理（SVG `feTurbulence`），讓它看起來像紙。
2. **彩虹層**：一條很寬的線性漸層（B 色票的雷射漸層，重複兩次），角度約 115°。`background-position` 隨傾斜角移動，所以換角度時顏色會在表面流動。用 `mix-blend-mode: color-dodge` 或 `overlay` 疊在紙上。
3. **星星網點遮罩**：一張用 SVG 畫的小星星和圓點重複圖樣，當作彩虹層的 `mask-image`。彩虹只從星星裡透出來，像防偽貼紙。郵票框和直排大標則用自己的形狀當遮罩，整片都是雷射。
4. **反光層**：一個白色的 `radial-gradient` 光點，位置跟著傾斜方向移到另一側，用 `mix-blend-mode: soft-light`，讓票有「被燈照到」的感覺。

**控制方式**
- 電腦：滑鼠在票上的位置換算成 −1～1 的 `--mx`、`--my`，票最多傾斜 ±14°，反光和彩虹位置同步移動。滑鼠離開時慢慢回正。
- 手機：用 `deviceorientation` 的 `beta`、`gamma`（以開封那一刻的角度當作基準），換算成同樣的變數。iOS 要在使用者點「開封」時呼叫 `DeviceOrientationEvent.requestPermission()`。沒授權或沒有陀螺儀時，改成用手指在票上拖曳。
- 所有數值都經過彈簧平滑（lerp），不會抖。

**無障礙與降級**
- `prefers-reduced-motion`：跳過飛出與碎紙，直接淡入票；雷射仍然可以傾斜，但幅度減半。
- 按鈕都可以用鍵盤操作，翻面後焦點留在翻面按鈕。
- 票面文字是真的 DOM 文字，不是圖片。

#### B7. 技術選擇：CSS 3D 的票＋three.js 的扣扣

票本身用 CSS 3D：票面是文字、細線和欄位，DOM 渲染比 WebGL 貼圖清楚，縮放也不會糊；傾斜、翻面、開信封都是幾個平面的 3D 變換。雷射材質靠 `mix-blend-mode` 和 `mask-image` 就能做到接近 shader 的效果，在手機上也省電。

扣扣用 three.js：載入 3D 扣扣的 GLB，放在一個透明背景的 canvas 裡，跟票疊在同一個畫面。扣扣住在郵票裡時，用 WebGL 的 scissor 把畫面裁到郵票的範圍，看起來像被印在郵票裡；要跳出來做動作時才解除裁切。扣扣在每個狀態都有戲份：

| 狀態 | 扣扣在做什麼 |
| --- | --- |
| 待開封 | 站在信封旁邊，發條鑰匙慢慢轉，身體不左右搖，只原地呼吸（整隻慢慢一伸一縮） |
| 開封 | 原地蹲低再跳起，跳到最高點時票從信封飛出 |
| 待出發 | 跳進黃色郵票，只在郵票框裡看得到（超出的部分被裁掉）；在郵票裡慢慢自轉，同時跟著票的傾斜和翻面一起轉，翻到背面時藏起來 |
| 已上車 | 從郵票跳出來到存根旁邊，整隻往前一撲（剪票鉗剛好對著存根），落下那一刻打出剪票孔，再跳回郵票 |
| 已抵達 | 從郵票跳得比較高，整隻往票面重重落下，像一顆印章；落地瞬間郵戳出現、整張票震一下，再跳回郵票 |

- 票、信封：DOM＋CSS 3D，狀態用 `data-state` 切換。
- 雷射：CSS 漸層＋混合模式＋SVG 遮罩，由 JS 寫入 CSS 變數。
- 背面主視覺：一個 three.js 月台場景，畫在背面的 canvas 上，鏡頭跟著票的傾斜繞動。翻到背面才開始渲染，翻回正面就停，省電。模型都用 gltf-transform 壓縮（meshopt＋WebP 貼圖），每個 2～5 萬面，整個場景控制在 30 萬面以內。月台模型等正面的扣扣載完才開始載，載好前背面只有紙色底，載好後淡入。左上角疊一層紙色漸層，讓標題壓在場景上也讀得清楚。
- 扣扣：three.js＋GLTFLoader，鐵皮材質用 `MeshPhysicalMaterial`（低粗糙度、有一點 clearcoat），發條鑰匙是獨立物件。模型由 Tripo 生成並 retopo（約 1.1 萬三角面），沒有骨架（自動綁骨架會讓剪票鉗那隻手變形），所以所有動作都是整隻身體的位移、旋轉和擠壓伸展（squash & stretch），用程式寫的緩動曲線控制。
- 碎紙：一個 2D canvas。
- QR code：用固定的假資料畫成 SVG（不需要掃得出東西）。
- 在 playground 的風格分類新增一個「雷射」（Holographic）。
